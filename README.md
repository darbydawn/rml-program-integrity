# Federal Research Governance & Program Integrity Analytics

## Overview

This repository contains an independent public-data analytics case study focused on federal research funding, contracting patterns, regulatory oversight, and program-integrity risk indicators.

The project uses publicly available sources such as federal spending data, federal award records, public agency reports, and public legal/regulatory documentation to demonstrate how analysts can organize complex healthcare and public-sector information into a structured governance review.

This work is intended as an analytics portfolio project. It is not legal advice, does not represent an official investigation, and should not be interpreted as an allegation of wrongdoing against any person or organization.

---

## Skills Demonstrated

- Public-sector data analysis
- Healthcare governance and program-integrity review
- Federal spending and contract analysis
- Risk-indicator identification
- Research documentation
- Python-based exploratory analysis
- Data visualization
- Evidence organization and executive reporting

---

## Project Questions

1. How are federal funds distributed across contractors, research programs, and supporting entities?
2. Are there patterns of contract concentration or unusual funding timing that warrant governance review?
3. How can public data be used to identify oversight questions without making unsupported conclusions?
4. What documentation and evidence structure helps convert complex public information into an analyst-ready report?

## Notes on Interpretation

The analyses in this repository are exploratory and based on public records. Public spending data can contain timing lags, award modifications, incomplete outlay fields, coding inconsistencies, and other limitations. Findings should be interpreted as governance questions or review prompts, not as final determinations.
